How to read the planner

Where to start

Start with the first title and go in order: it is release order, the best one for a first watch. Tick every title you have seen: the planner shows you the next one.

Want to follow the story?

Some titles, like Captain America: The First Avenger and Captain Marvel, are set in the past. To see them in story order, choose Chronological.
