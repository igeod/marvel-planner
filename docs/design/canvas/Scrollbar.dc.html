Esempio

Elenco scorrevole con la classe .scroll-y (overflow-y: auto, overscroll-behavior: contain, scrollbar-gutter: stable). Il pollice cambia con hover. L'anteprima di questo canvas è senza mouse fine: la barra a pillola si vede solo in un browser con mouse o trackpad.

Quando si applica

  • Solo con (hover: hover) and (pointer: fine): mouse o trackpad.
  • Firefox: proprietà standard scrollbar-width: thin e scrollbar-color. Chromium e Safari: ::-webkit-scrollbar, senza le proprietà standard (altrimenti torna la barra di sistema con le frecce).
  • Pulsanti con le frecce: nascosti.
