  • Add and remove are reversible: toast, never a confirmation popup.
  • Undo restores the title at its previous position and shows no second toast. Available for the toast duration (8s).
  • Guest add uses the check icon and the action Sign in. Pressing it opens the Login required popup; the title stays in the list either way.
  • Rapid changes: the toast is replaced, not stacked. Adding several titles within 2s merges into one toast with a count.
  • Errors: role="alert", stay until dismissed, the change is rolled back in the UI, action Retry.
  • Copy: sentence case, result first, max 8 words, no full stop. The title name may replace “Added” subject when there is room (“Thor added to your list”), not on mobile.
  • Announce: role="status" so screen readers read it without moving focus. Add button label changes to “Remove from list” right away.

Use

  • Reversible actions (mark as watched, mark all, apply filters): act at once, show a toast with Undo. No confirmation popup.
  • Irreversible actions (reset progress): destructive popup, see Popup.
  • Motion: enter --dur-enter from 8px below with fade, exit --dur-ui. None under prefers-reduced-motion.
  • One toast at a time. A new one replaces the old. Copy: sentence case, result first, max 8 words.
