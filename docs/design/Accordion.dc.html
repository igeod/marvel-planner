Accordion

The planner has two nested accordions, both native <details>/<summary>. The phase groups its titles in one container. The title row opens into a dark panel with poster, synopsis and prerequisites. Open state lives only while the page stays open.

Dimensions and tokens

  • Phase container (<details>): bg --surface, radius 32px, padding 10px, gap 6px between header and rows. Header and rows are one visual group, never separate cards.
  • Phase header (<summary>): min-height 64px, padding 10px 16px 10px 18px (mobile 10px 12px 10px 14px), radius 22px (visible on hover). Name 20px 800, years 14px --ink-2, count "2 of 6" 16px 700, chevron 24px (stroke 2.6) vertically centered at the right.
  • Title row closed (<details> inside the row): bg --bg, radius 22px, padding 10px 16px 14px 8px (mobile 10px 12px 14px 4px), gap 12px (mobile 8px). Container padding 10px minus row radius 22px gives the 32px outer radius: inner radius = outer radius minus padding, so header and rows stay concentric. Checkbox hit area 44x44 (centered on the 64px thumbnail: margin-top 10px), thumbnail 44x64 radius 14px, name 18px 800 + meta 14px, chevron 24px centered.
  • Title row open: bg --panel, text --on-dark. Thumbnail grows to 96x144 (mobile 72x108). Everything in the right column shares one left edge: header, "Mark as watched" pill, synopsis, Before you watch, Full details (right-aligned). The checkbox is hidden while open (kept in the DOM).
  • Chevron: lucide chevron-down, rotates 180deg when open. It is decorative (aria-hidden); state is exposed natively by <details open>.
  • Empty phase: container with header only plus one line "No titles in this phase" 14px --ink-2 padding 12px 20px.

Behavior and motion specification

  • Markup: keep native <details>/<summary>. Phase: details > summary plus the list. Title: row li with the checkbox outside the summary, so toggling the state never opens or closes the row. The whole summary is clickable, min 44px. Never nest the checkbox inside the summary.
  • Keyboard: Tab reaches each summary and each checkbox, Enter and Space toggle, no custom arrow-key model. Focus ring: 3px inset outline (offset -3px) so it is never clipped by the container radius; --red on light rows, --gold on dark rows.
  • State: phase open/closed persists while the page is open (useCollapsedPhases); title rows are independent, several can be open. "Collapse all / Expand all" acts only on phases. Opening a title for the first time lazy loads its content (loading, error with retry, loaded), see the content states above.
  • Hover (@media (hover:hover)): header and row background step one tone (phase header var(--bg) on light, closed row one step darker, open row one step lighter). Pressed: one more step, no scale (rows are large). Disabled: not applicable.
  • Open animation: three things at once. (1) Chevron rotates 180deg, var(--dur-ui) var(--ease-out). (2) Height: var(--dur-enter) var(--ease-out) via the Chromium/Safari details::details-content { transition: block-size var(--dur-enter) var(--ease-out), content-visibility var(--dur-enter) allow-discrete; } details { interpolate-size: allow-keywords; }; where unsupported the content simply appears (no polyfill). (3) Content fades and rises: opacity 0 to 1 in --dur-hover and translateY(4px) to 0 in --dur-enter. Open title also changes color: row bg and text crossfade --bg to --panel in --dur-ui and the thumbnail grows (44x64 to 96x144) in --dur-enter. If growing the thumbnail causes layout jank, snap it and keep the others.
  • Close animation: faster than open: --dur-ui height, var(--dur-press) fade.
  • Collapse all / Expand all: phases animate together with a --stagger-step stagger (capped at --stagger-max) from top to bottom, maximum 6 steps; none under reduced motion.
  • Watched: the checkbox fills in --dur-ui; the name strike-through shows only while the row is closed and fades in --dur-ui. Strip cells in the progress block crossfade in --dur-hover.
  • Scroll behavior: opening a title never scrolls the page by itself unless the opened panel's bottom is below the viewport, then scroll it into view smoothly with scrollIntoView({block:"nearest"}) (reduced motion: instant) after the open animation ends.
  • Reduced motion: no height, rotation, translate or thumbnail growth: content appears at once; keep the --dur-press background crossfade and the focus ring. Loading skeleton pulse becomes static.
  • Mobile: same behavior; padding and thumbnail sizes in the anatomy list. Content column starts after the thumbnail; if the title is very long, wrap to 3 lines max with no truncation of the name.
  • Tokens: --ease-out: var(--ease-out). Never transition: all and never animate height directly with fixed pixel values.
