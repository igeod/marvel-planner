Tooltip

One info icon opens a short hint. It opens on hover, on keyboard focus and on tap, closes on Esc, leave, blur or a second tap. Use it for a single sentence of context, never for information the user needs to act.

Used wherever something hides spoilers (reasons, plot, post-credits scenes, key scenes). Trigger is the warning-triangle icon in gold (var(--highlight)), bubble is gold with ink text var(--ink) and weight 700. Copy rules: one short line, light humor, max 8 words, same wording for every spoiler spot, translated (not literal) in each language.

Specification

  • Trigger: button, 44x44 hit area, 20px lucide info icon (circle with i), stroke 2.2, color muted (--ink-2 / --muted-on-dark), fully round. Needs a text aria-label naming what the hint is about, and aria-describedby pointing at the bubble.
  • Bubble: role="tooltip", radius 14px, padding 10px 14px, 14px / 1.35, weight 600, max width 240px, left aligned, 4px gap from the trigger, 10px rotated square tail (radius 2px). No shadow, no border. Contrast at least 4.5:1.
  • Open: hover (only @media (hover:hover), --delay-tooltip delay), keyboard focus (no delay), tap on touch (toggle). Close: Esc, mouse leave, blur, tap outside, second tap. Hovering the bubble keeps it open.
  • Placement: top by default, flips to bottom when there is no room, then left/right. Keep inside the viewport (8px margin). Implement with the Popover API plus CSS anchor positioning, with a measured position: fixed fallback so it is never clipped by overflow.
  • Motion: fade and 4px translate toward its final position, --dur-hover in, --dur-press out, --ease-out; none under prefers-reduced-motion.
  • Content: one sentence, plain text, no links, no spoilers. If the user must act on it, it is not a tooltip: show it inline.
  • Component: InfoTip (props: label, children text, optional placement, tone auto-detected by surface: inverse-light or inverse-dark).
