Tastiera, accessibilità, casi limite

  • L’occhio ha aria-label ("Mostra" / "Nascondi"), aria-expanded e aria-controls sul contenuto; il contenuto è una region con aria-labelledby sul titolo.
  • Chiuso, i pulsanti interni escono dall’ordine di tab (il contenuto è inert).
  • Tooltip warning: "Spoiler alert! Peek only if you dare." (vedi Tooltip, tono warning).
  • Contenuto più alto del box: scorre dentro il box; il box non cambia altezza.
  • Altezze dei box nella zona spoiler: regola della schermata, vedi Pagina Film.
